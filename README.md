# Agent Skills

A collection of reusable skills for AI coding agents.

## Available Skills

| Skill                                            | Description                                                                                                             |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| [strict-block-style](skills/strict-block-style/) | Enforces consistent JavaScript and TypeScript control-flow formatting, including mandatory braces and blank-line rules. |

## Installation

Install skills using the [Skills CLI](https://skills.sh).

### Install interactively

```bash
npx skills add zwe1ch/skills
```

### Install a specific skill

```bash
npx skills add zwe1ch/skills --skill strict-block-style
```

### Install globally

Use `-g` to make skills available across projects.

```bash
npx skills add zwe1ch/skills -g
```

### Update installed skills

```bash
npx skills update
```
